📌 Overview

AI Code Editor & Reviewer is a full-stack AI-powered development platform where users can:

✍️ Write code
🤖 Generate code using AI
🔍 Review and optimize code
✏️ Edit code in real-time
▶️ Run/execute code inside the editor

It combines AI + Code Execution + Smart Review System to create a powerful developer experience similar to modern AI coding tools.

🔥 Core Features
🧠 AI Code Generation (Prompt → Code)
🔍 AI Code Review & Optimization
✏️ Live Code Editing (Editor Support)
▶️ Code Execution (Run inside editor)
💬 Prompt-based interaction system
🔐 Authentication System (JWT आधारित)
🧑‍💻 GitHub OAuth Login Integration
⚡ Fast API Response (Optimized Backend)
🧠 How It Works
User writes a prompt or code
Backend processes the request
AI API (Groq / Claude) generates or reviews code
Response is returned to the editor
User can edit and run code in real-time
